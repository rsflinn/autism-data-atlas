# ACMG/AMP variant classification specifications from the ClinGen Epilepsy Sodium Channel Variant Curation Expert Panel.

## Key Findings
ClinGen gene-specific ACMG/AMP rules for SCN1A/SCN2A/SCN3A/SCN8A/SCN1B. Three (SCN1A, SCN2A, SCN8A) are in the 49-gene set and span the autism-epilepsy overlap. A coding-variant interpretation framework (mostly missense/PTV, minimal noncoding), useful as a classification reference rather than a regulatory-variant finding.

## Relevance to Atlas
Standardized classification for sodium-channel genes central to the autism-epilepsy ion-channel theme; the project's individual-gene overlap signal (SCN2A) sits here. Coding-focused, so it constrains interpretation, not regulatory burden.

## Genes
SCN1A, SCN2A, SCN8A

## Methods
Expert-panel rule adaptation; pilot on 37 variants spanning types and prior classifications; paralog and functional-assay criteria.
